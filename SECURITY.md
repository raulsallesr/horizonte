# Segurança

## Versões suportadas

Somente a versão publicada mais recente recebe correções de segurança.

## Como reportar

Não publique dados sensíveis em uma issue. Prefira o recurso de relato privado de vulnerabilidade do GitHub, quando disponível; caso contrário, contate o mantenedor pelo perfil `@raulsallesr` antes de compartilhar detalhes técnicos.

Inclua impacto, passos mínimos para reproduzir e a versão afetada. O recebimento será confirmado assim que possível, sem promessa de prazo fixo para correção.
